# Publish to GitHub

```bash
git init
git add .
git commit -m "Update: B1.2 start - Doppelkonnektoren + vocab"
git branch -M main
git remote add origin https://github.com/<your-username>/german-grammar-notes.git
git push -u origin main
```
Use a Personal Access Token as password. Enable Pages: Settings → Pages → branch gh-pages.
